# Harsha Gypsum - Website Penjualan List Profil Gypsum, Wall Moulding & Plafon

Website e-commerce katalog dan landing page profesional untuk penjualan **List Profil Gypsum, Ornamen Plafon, Wall Moulding, Shadowline Tali Air, dan Aksesoris Pemasangan**.

Didesain dengan tampilan modern dan mewah (*architectural luxury theme*), super ringan (Pure HTML, CSS, JS), akses instan, ramah pengguna ponsel (*mobile-friendly*), serta terintegrasi langsung dengan pemesanan WhatsApp.

---

## 🌟 Fitur Utama
- **Katalog Motif Interaktif:** Filter kategori (*Minimalis, Klasik Ukir, Shadowline, Wall Moulding, Ornamen Plafon, Aksesoris*), live search, dan sorting harga.
- **Kalkulator Kebutuhan Gypsum:** Menghitung keliling ruangan, estimasi kebutuhan batang list (+ cadangan potongan miter 10%), serta perkiraan biaya & sak kompon.
- **Keranjang Pesanan (Inquiry List):** Pelanggan dapat mengumpulkan pesanan beberapa jenis motif sekaligus.
- **Direct WhatsApp Order:** Tombol order dengan template pesan yang otomatis terisi nama motif, kode, dimensi, jumlah batang, dan total estimasi harga.
- **Mobile-Friendly:** Navigasi bawah (*bottom bar*) ala aplikasi smartphone dan *drawer menu* responsif.

---

## 🚀 Cara Menjalankan

1. **Menggunakan Web Server Lokal (XAMPP):**
   - Letakkan folder ini di `c:/xampp/htdocs/Gypsum`
   - Nyalakan Apache pada XAMPP Control Panel
   - Buka browser: `http://localhost/Gypsum/`

2. **Menggunakan Python Web Server:**
   ```bash
   python -m http.server 3000
   ```
   Buka browser: `http://localhost:3000/`

3. **Membuka File Langsung:**
   - Cukup buka `index.html` pada browser Chrome / Edge / Firefox.
